# The Moonbell Mix-Up

A whimsical, original top-down pixel-art adventure. The moon has misplaced its
bedtime bell, and Noodlewick's residents are having a very long day. Set out
with Pip, your floating lantern-sprite companion. Talk to Auntie Fizz, chase
the grumble-moths through the Upside-Down Woods, find the bell in the Teacup
Catacombs, and bring it home before the moon gets cranky. There is also a
secret glen, a suspicious chest, and a fizzy plum tonic. The world now has a
central river island, plank bridges, a forest pond, a mountain pass, a cave,
and a hilltop keep.

## Run

Open `index.html` in a modern browser. No install or build step is required.

## Controls

- Move: `WASD` or arrow keys
- Fire a star spark (hold to fire): `Z` or `Space`
- Talk / interact: `E`
- Use a fizzy plum tonic: `Q`
- Start or retry: `Enter`

The top-right world map shows how the four regions connect. The cyan marker
shows your position in the current region, and a gold marker points to your
current story objective when one is active. In the Upside-Down Woods, look for
the northern trail to find the optional Hush-Hush Glen.
