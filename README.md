# Starfall Trail

A small, original browser action-RPG prototype. Explore the trail, use pulse
attacks to fend off dusklings, and activate all three sky beacons.

## Run

Open `index.html` in a modern browser. No install or build step is required.

## Controls

- Move: `WASD` or arrow keys
- Pulse attack: `Z`
- Activate a nearby beacon: `E`
- Start or restart: `Enter`
